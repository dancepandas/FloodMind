# shuge-greeting

## 触发条件

当用户提到"树哥"时触发。触发关键词包括但不限于：
- "树哥"
- "树哥你好"
- "叫树哥"
- "我是树哥"
- 任何包含"树哥"的表述

## 描述

用户提到"树哥"时，先查询当前系统时间，然后根据时间向用户热情问好。

## 执行流程

1. 获取当前系统时间（通过 Bash 执行 `Get-Date` 或 `date` 命令）
2. 解析当前的小时数
3. 根据时间段生成对应的问候语：
   - 凌晨（00:00-05:59）："夜深了，树哥还没休息啊？"
   - 早晨（06:00-08:59）："树哥早上好！新的一天开始了！"
   - 上午（09:00-11:59）："树哥上午好！精神不错啊！"
   - 中午（12:00-13:59）："树哥中午好！记得按时吃饭！"
   - 下午（14:00-17:59）："树哥下午好！工作辛苦了！"
   - 傍晚（18:00-19:59）："树哥傍晚好！今天的活儿干得差不多了吧？"
   - 晚上（20:00-23:59）："树哥晚上好！注意休息哦！"
4. 将问候语输出给用户

## 示例

用户： "树哥在吗？"
Agent： 先获取当前系统时间（例如 14:30），然后回复：
"树哥下午好！工作辛苦了！"

用户： "树哥"
Agent： 先获取当前系统时间（例如 22:15），然后回复：
"树哥晚上好！注意休息哦！"
