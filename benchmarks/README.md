# benchmarks — 能力基线测量

存放用于回答“某个能力是否值得启用”的可重复测量，而不是产品代码。当前只有多代理基线。

## 子目录

| 目录 | 作用 |
| --- | --- |
| `multi_agent/` | 对比单代理与委派策略（`SubAgent` / `ParallelTask`）的成功率、token、耗时与委派次数 |

## 约定

- 默认命令只列任务，不调用模型；只有显式 `--live` 才读取模型配置并发起真实请求。
- CI 不运行 `--live`。
- 每个任务使用独立临时 workspace，结束后清理。
- 单次运行只适合基线或发现明显退化；小方差差异需要多次取样。
