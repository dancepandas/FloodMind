# 变更验证矩阵

每个 PR 选择所有适用行，记录实际命令、结果与未跑原因；一条局部测试不能替代全量回归。

| 变更 | 最低附加证据 |
| --- | --- |
| 工具/schema/输出 | 成功、非法参数、异常；拒绝不执行；有副作用时检查真实结果、超时与重试 |
| 权限/路径/命令/网络 | 允许、拒绝、问询及不可绕过；planning/subagent 限制；真实资源边界 |
| 执行器/预算/并发/取消 | 组装运行时轨迹、预算终止、取消和并发故障；验证任务结果而非自报 |
| 事件/持久化/恢复 | 生产者消费者、序列化往返、顺序/重复、失败恢复及唯一状态源 |
| Provider/模型协议 | 确定性传输替身、流与非流、工具调用、错误与中断 |
| Skill/MCP/插件 | 注册与资源、失败隔离、生命周期实际调用路径、权限与清理 |
| 公共 SDK/打包/依赖/资源 | SDK purity、公开导入、sdist→wheel 隔离安装及 CLI |
| 文档示例/公开签名 | 登记示例编译执行、真实契约组装测试、所有消费者同步 |
| CI/检查脚本 | 正负退出码、上游失败/取消/跳过、真实脚本执行，不只测 Mock |
| 结构/职责调整 | 依赖方向、公共边界、相关规范与知识图谱同步 |

所有代码变更至少跑全量 `python -m pytest -q`。影响运行时行为时还要跑 rule judge 校准及确定性 eval；交付变更运行产物检查。纯文本修订可在 PR 中说明不适用项，但带可执行示例的文档不属于免测文本。

测试名称不等于覆盖证据：报告中写清输入、观察结果、命令和平台。跳过必须解释原因与剩余风险，不能标记为通过。发现既有失败也要按名称报告，不允许隐去。
