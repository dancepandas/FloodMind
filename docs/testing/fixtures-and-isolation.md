# 测试夹具与隔离

- 使用 `tmp_path`/临时目录作为工作区、journal、记忆和配置根；需要时设置 `FLOODMIND_HOME`，不得覆盖真实用户配置或 `.floodmind/mcp.json`。
- 使用 monkeypatch 管理环境变量和替身生命周期；测试后恢复。模型 API 密钥只能由环境提供，默认测试不得需要密钥。
- 默认隔离 MCP servers 和网络；外部 HTTP/模型响应在传输边界替换。不得 Mock 被验证的权限决策或工具执行结果，再声称端到端成功。
- 文件/进程类用例检查实际产物、返回码和清理；失败路径同样清理。异步/后台线程使用明确同步，不以不确定 sleep 掩盖竞态。
- 平台专属用例用明确 `skipif` 并给理由，不能删除 Windows 或 POSIX 用例换取绿灯。
- 不依赖执行顺序、仓库内固定报告文件、开发机缓存、全局 registry 或现有 venv。
- 回归测试说明缺陷输入与可观察后果，并确认缺陷存在时测试失败；避免只断言 Mock 调用次数。
- 报告不得包含密钥、个人目录内容或真实业务数据；内置夹具应最小化且可公开。

组装用例需要指出哪些服务是真的、哪些边界被替换。纯只读工具测试的临时 authority 不是合法持久化事务实现，不能移植到生产宿主。
